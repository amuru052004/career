#  AI Career Counselor

Welcome to the AI Career Counselor project – a personalized career guidance tool built using **Generative AI**. This application helps users explore suitable career paths based on their **skills, interests, education level** using the power of LLMs.

##  Features

- ✅ Personalized career suggestions
- ✅ Skill and gap analysis
- ✅ Generative AI-powered guidance
- ✅ Simple and interactive Streamlit interface

##  Tech Stack

- **Python**
- **Streamlit** – For frontend UI
- **OpenAI GPT** – For generative response
- **Google Colab** – Model development
- **GitHub** – Code versioning
